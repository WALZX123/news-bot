# 排序启发式的回归边界

排序先限制候选规模，再计算来源权重、标题相似报道的独立来源数及时间。批次分析中的 `_selection` 保存实际新闻 ID、独立来源数和权重，便于复核。

公共流水线回归固定以下样本：同一来源两篇同题稿只计一个来源；加入独立第二来源后计两个；内容明显不同的体育报道单独计一个。大小写归一化不改变英文标题含义。超过每轮上限的新闻保留 pending。

这是标题相似度启发式，来源数只用于阅读排序。它不核验两篇报道的事实是否一致，不承诺识别改写或跨语言同一事件。真实选题应用应定期扩充人工标注样本，分别记录误合并和漏合并；没有标注集的实测准确率时，不应宣称已经实现语义交叉核验。
